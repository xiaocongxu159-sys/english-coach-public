# B1 Vocabulary + Skill Node Inventory

**Task:** P0-CUR-005B  
**Version:** v1.0-draft  
**Date:** 2026-09-01  
**Status:** Detailed B1 vocabulary/skills baseline

## 1. Purpose

This document completes the B1 node-level curriculum design by adding Vocabulary (`VX`), Pronunciation (`PR`), Listening (`LS`), Speaking (`SP`), Reading (`RD`) and Writing (`WR`) nodes to the validated B1 Grammar/Communicative Function layer.

B1 is an **independent-user bridge**: learners should handle familiar work, study, travel and social situations; follow the main points of clear standard input; produce connected language; explain experiences, plans and reasons; and sustain familiar conversations despite visible planning, hesitation and repair.

# 9. B1 integrated exit profile

A learner approaching B1 completion should be able to:

- follow the main points and important details of clear standard speech on familiar work, study, travel and personal topics;
- enter unprepared conversation on familiar/personal-interest topics and sustain it through follow-up, clarification and repair;
- narrate experiences/events in connected sequence and distinguish common past/present-perfect meanings;
- state and support an opinion, compare options, give basic pros/cons, advice and limited speculation;
- handle many travel/service/work problems independently enough to seek a practical solution;
- participate in routine meetings, calls and interviews and give a simple progress update;
- give a structured 1–2 minute talk and summarize straightforward information;
- read longer everyday/informational/workplace texts for main point, support, reference, fact/opinion and specific detail;
- write connected emails, narratives, opinion paragraphs, problem/solution texts, summaries and practical work messages;
- speak comprehensibly in longer stretches with visible but manageable pausing/planning/repair.

B1 is not equated to an IELTS band. It provides a substantial general-English base onto which increasingly explicit IELTS practice can be mapped.
